Long-standing issues 480, 481, 483 are finally done. Pulp is now much closer to full conformance with the OCI distribution spec, so more clients and tools like regctl, crane and skopeo work against it unmodified. Also fixed: PATCH on a blob upload now returns 202 per spec (2.27.2).
REPOSITORIES · 2.29
Push repositories become regular repositories
A podman push now creates a ContainerRepository, not a ContainerPushRepository.
One repository type to sync, push, copy and tag. The push-only type will be phased out in a future release.
MIGRATE EXISTING ONES IN PLACE
POST …/repositories/container/ container-push/<pk>/migrate/
Primary key and full version history preserved; only the type changes.
PulpCon 2026 · pulp-container   |   5
Speaker notes
This is a big quality-of-life change. Previously pushed repos couldn't be synced into, which forced awkward workflows. Existing push repos can be migrated in place with the new migrate endpoint.

PulpCon 2026 · pulp-container   |   6
Speaker notes
include_tags and exclude_tags are renamed; update your automation. The digest support is the headline: you can pin exactly the manifests you want. The companion-tag fix was also backported to 2.27.9. Explicitly exclude sha256-* on the remote to skip .sig, .att, .sbom and bare digest companion tags. Exclusions also apply during automatic companion discovery. Source: pulp_container/app/tasks/sync_stages.py and tests/functional/api/test_sync_signatures.py.

BEFORE YOU UPGRADE TO PULPCORE 3.117+
Repair pull-through distributions first.
pulpcore-manager container-repair-pull-through-distributions
Shipped in 2.19.14, 2.20.12, 2.22.11, 2.24.13, 2.26.17, 2.27.12, 2.29.1 and 2.30.0 (#2494).
Speaker notes
Call this out loudly. Pull-through distributions created before the fix may overlap other base paths; they need repairing before upgrading to pulpcore 3.117 or later. The database overlap constraint first shipped in pulpcore 3.117.0. Backports shipped September 23, 2026. Declared pulpcore ranges at those tags: Container 2.19.14 and 2.20.12 >=3.49.0,<3.55; 2.22.11 >=3.49.0,<3.70; 2.24.13 >=3.73.0,<3.85; 2.26.17 >=3.73.2,<3.100; 2.27.12 >=3.73.2,<3.115; 2.29.1 >=3.111.0,<3.130. Container 2.30.0 requires >=3.118.0,<3.130. No backport to 2.28. Sources: https://github.com/pulp/pulp_container/issues/2494 and requirements.txt or pyproject.toml at the release tags.

FIXES WORTH KNOWING
Security and Flatpak fixes
Security
  • CVE-2026-103868: global auth token leakage, fixed on every supported branch (2.19 → 2.30)
  • Remote credentials could leak to another registry via a shared headers dict
  • Blob downloads respect each Domain's storage redirect setting
Flatpak index
  • OS and architecture filters actually filter
  • Domain-aware: correct prefixes, no cross-domain cache collisions
  • Correct registry host when CONTENT_ORIGIN is unset
